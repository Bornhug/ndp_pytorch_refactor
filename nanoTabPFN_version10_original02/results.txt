



Training with 30k steps and Evaluation with max_columns 32 features filter

For nanoTabPFN_version10_original02, evaluation now works like this:
1.	Load the 29 TabPFN regression benchmark datasets from OpenML in tabarena_eval/evaluation.py.
2.	Preprocess features:
•	drop constant columns
•	coerce numeric columns to float
•	ordinal-encode categorical columns
•	fill remaining missing x with 0.0
3.	Skip any dataset whose processed feature count is greater than 32.
4.	If a dataset has more than 200 rows, subsample exactly 200 rows using np.random.default_rng(random_state).choice(...).
5.	Use one fixed random_state, so the subsampled dataset and CV split are fixed.
6.	Run 5-fold shuffled CV:
•	train on 4 folds
•	test on 1 fold
•	repeat until every fold has been the test fold once
7.	For each dataset, concatenate predictions from the 5 test folds and compute:
•	R2
•	RMSE
•	MAE
8.	For the overall result, average the fold-level overall scores across the 5 folds, and also report standard error:
•	r2, r2_se
•	rmse, rmse_se
•	mae, mae_se
